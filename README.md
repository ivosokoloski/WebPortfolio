# Portfolio Website

[🔗 Web Portfolio ](https://ivosokoloski.vercel.app/)

**Portfolio Website** is a personal React application built to showcase engineering projects, skills, and professional identity. The project focuses on high performance and a unique, custom-designed user interface.

📌 **Description**

The application serves as a digital resume and project showcase platform. 
The purpose of the project is to provide a seamless user experience while demonstrating advanced front-end development skills and design principles.
The project is developed as an exercise for:
* Mastering the **React** component-based architecture
* Building complex layouts with **Custom CSS** (no UI frameworks)
* Implementing **Responsive Design** for all device types
* Managing state and navigation in a Single Page Application (SPA)

🧱 **Architecture**

The application is built with a modern front-end approach:
* **Modular Components** – Each section (Header, About, Projects, Contact) is a separate reusable component.
* **Dual-Panel Layout** – A fixed 20% sidebar for identity and an 80% scrolling area for content.
* **CSS Variable System** – Centralized theme management for neon accents and dark-mode aesthetics.
This approach ensures clean code, easy maintenance, and extremely fast load times.

⚙️ **Functionalities**

* **Dynamic Scrolling** – Smooth navigation between sections without page refreshes.
* **Project Showcase** – A structured grid displaying technical projects with direct links.
* **Mobile Drawer** – A custom-built mobile menu and navigation system.
* **Asset Integration** – Direct download functionality for the CV and integrated contact methods.
* **Interactive UI** – Hover effects and animations built with cubic-bezier transitions.

🎨 **Design (Cyber-Minimalist)**

The application integrates a custom "Cyber" aesthetic, through which the following are implemented:
* **Neon Accents** – Strategic use of neon-cyan for high-tech visual feedback.
* **Glassmorphism** – Subtle blur and transparency effects for a modern feel.
* **Vector Precision** – Use of inline SVGs for crisp, scalable icons and logos.
This approach enables a professional, technical look that reflects an engineering background.

🛠️ **Technologies Used**

* **React.js**
* **JavaScript (ES6+)**
* **Custom CSS3** (Flexbox & Grid)
* **SVG Graphics**
* **Vercel** (for Deployment and CI/CD)

🎯 **Project Goal**

The goal of this project is:
* Practicing **React** development and component state management.
* Gaining deep knowledge of **CSS layouts** and advanced animations.
* Creating a professional **live presence** on the web.
* Preparation for professional collaborations and technical roles.

📌 The project is a live production-ready application intended to bridge the gap between technical engineering skills and creative front-end presentation.
